# 스파이크: SMPL 평균 체형 A자세 내보내기와 신체 측정 (D2)

작성 2026-11-10 · 관련 이슈 #7 · 상태: 코드와 합성 몸 검증 완료, **실제 SMPL 모델 실행 전**(모델 파일 미보유)

SMPL 평균 체형을 A자세로 내보내 C의 착장 스파이크 입력(OBJ)으로 넘긴다. 몸 메시에서 신체 치수 5개(키·가슴둘레·허리둘레·어깨너비·팔길이)를 재는 함수도 만든다. 이 함수는 D3에서 사용자 치수에 맞춰 몸을 만들 때 목표값과 비교하는 데 쓴다.

## 1. 구성

| 위치 | 하는 일 |
|---|---|
| `fitting/adapters/smpl/model.py` | SMPL 모델 파일 읽기, 체형(betas)·자세 적용(linear blend skinning), A자세, OBJ 저장. numpy만 쓴다(torch 불필요) |
| `fitting/body/measure.py` | 메시·관절·스키닝 가중치에서 치수 5개를 잰다. 외부 SDK나 어댑터를 import하지 않는 로직 코드 |
| `tools/smpl_body.py` | 모델 → A자세 → 측정 → `body_apose.obj`, `measurements.json`, `debug_front.png` |
| `models/README.md` | SMPL 모델을 받아 두는 방법. 모델 파일은 커밋하지 않는다 |

**모델 파일 읽기**
- 공식 `.pkl`에는 chumpy 객체가 섞여 있다. chumpy는 오래돼 새 Python에서 설치가 잘 안 되므로, 제한된 언피클러로 배열만 꺼낸다.
- numpy·scipy.sparse 외의 클래스는 불러오지 않는다. pickle을 통한 임의 코드 실행을 막으려는 것이다.
- `.npz`도 읽는다.
- **실제 모델 파일로는 아직 확인하지 않았다.** chumpy 객체에서 배열을 꺼내는 방식(`x` 속성)은 4절의 실행으로 확인한다.

**좌표**: y가 위, z가 앞(몸이 보는 방향), x가 몸의 왼쪽이다. 단위는 미터이고, 치수는 cm로 바꿔 소수 첫째 자리까지 쓴다.

## 2. A자세

- SMPL의 기본 자세는 T자세다. 왼쪽·오른쪽 어깨 관절을 z축으로 각각 −45°·+45° 돌려 팔을 45° 내린다(`--arm-angle`로 바꿀 수 있다).
- 45°는 천 시뮬레이션에서 팔과 몸통 사이에 틈을 두려고 고른 값이다. C의 스파이크 결과를 보고 조정한다.
- OBJ는 미터 단위 그대로 저장한다(SMPL·Blender 기본).

## 3. 측정 정의 (임시)

입력 화면의 '재는 법'(A2)과 같은 위치를 재도록 정했다. 팀 공통 기준(#1)의 측정 위치가 정해지면 고친다.

| 치수 | 정의 | A2 재는 법과의 대응 |
|---|---|---|
| 키 | 메시의 가장 높은 점과 가장 낮은 점의 높이 차 | 정수리~발바닥 |
| 가슴둘레 | spine3 관절 높이부터 어깨 관절 4cm 아래까지 15단계로 수평으로 자르고, 몸통 단면의 볼록 둘레 중 가장 큰 값 | 겨드랑이 아래, 가장 두꺼운 곳, 수평 |
| 허리둘레 | spine1 관절 높이에서 몸통 단면의 볼록 둘레 | 배꼽 높이, 수평 (spine1 높이를 배꼽 높이 근사로 씀) |
| 어깨너비 | 좌우 어깨 끝점 사이 직선거리. 어깨 끝점은 어깨 관절 높이부터 8cm 위까지에서 그쪽으로 가장 바깥 정점 | 어깨 끝 뼈 사이, 줄자를 곧게 폄 |
| 팔길이 | 왼쪽 어깨 끝점 → 팔꿈치 관절 → 손목 관절 거리의 합 | 어깨 끝 뼈 → 팔꿈치 → 손목 뼈 |

- **둘레**: 줄자는 오목한 곳을 건너뛰므로 단면의 볼록 껍질 둘레를 쓴다.
- **팔 정점 제외**: 스키닝 가중치가 가장 큰 관절이 팔인 정점(면)은 몸통 단면에서 뺀다. A자세에서 팔이 겨드랑이 근처 단면에 섞이지 않게 하려는 것이다.
- **정점 번호 대신 관절·가중치 사용**: 특정 정점 번호(랜드마크 표) 대신, 모델 파일에 들어 있는 관절 회귀 행렬과 스키닝 가중치를 쓴다. 정점 번호를 외워 쓰다 틀리는 위험을 피하려는 것이다.
- **D3에 미치는 영향**: 측정 정의가 사람이 줄자로 잰 값과 어긋나면, D3이 그 차이만큼 몸을 크거나 작게 만든다. 그래서 4절 실행 뒤 `debug_front.png`로 위치를 눈으로 확인한다.

## 4. 실행 방법과 확인

```bash
python -m venv .venv
source .venv/Scripts/activate        # PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements-body.txt
python -m pytest tests                # 합성 몸·작은 합성 모델 테스트(모델 파일 불필요)
```

SMPL 모델을 `models/smpl/`에 둔 뒤 실행한다(`models/README.md`).

```bash
SMPL_MODEL_PATH=models/smpl/basicmodel_neutral_lbs_10_207_0_v1.1.0.pkl python -m pytest -m smpl
python -m tools.smpl_body --model models/smpl/basicmodel_neutral_lbs_10_207_0_v1.1.0.pkl
```

`-m smpl` 테스트는 아래 네 가지를 확인한다.
- 모델 배열 크기: 정점 6890, 면 13776, 관절 24
- 좌우 방향: 왼쪽 관절이 +x
- A자세: 손목이 어깨보다 아래·바깥
- 평균 체형 치수가 넓은 성인 범위 안에 있는지, betas를 바꾸면 치수가 바뀌는지

**합성 몸 검증 결과** (원기둥으로 만든 몸, 정답을 식으로 계산)

| 키 | 170.0 cm | 170.0 cm |
| 가슴둘레 | 94.2 cm | 반지름 15cm 64각형 둘레 94.2 cm |

## 6. 열린 질문과 다음 단계

- 팀 공통 기준(#1)의 측정 위치가 여기 정의와 다르면 `measure.py`와 A2의 재는 법을 같이 고친다.

- 어깨 끝점이 삼각근 바깥쪽에 잡혀 실제 어깨뼈 끝보다 넓게 나오는지 확인한다.
- D3(사용자 치수에 맞춘 몸 생성): 이 측정 함수와 목표 치수의 차이를 줄이도록 betas를 최적화한다.
