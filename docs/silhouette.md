# 실루엣 검증용 렌더 쪽 기준 (C6)

작성 2026-11-24 · 관련 이슈 #11 (#8) · 상태: 마스크 정의·형태 값 함수·시연 2벌 실측 완료, 기준값은 모두 **[제안]**(D6와 합의 필요)

D6가 실사 영상 프레임의 옷 실루엣을 렌더와 비교할 때 쓰는 **렌더 쪽 기준**이다. (1) 렌더 옷 마스크가 무엇을 뜻하는지, (2) 마스크에서 재는 형태 값, (3) "같은 옷으로 볼 수 있는 범위"의 [제안] 값과 그 근거 실측을 적는다. **판정은 하지 않는다.** 통과·실패 기준과 판정은 D6가 정한다.

## 1. 렌더 옷 마스크의 정의

C5 렌더 어댑터(`fitting/adapters/blender/blender_render.py`의 `render_mask`)가 지금 하는 그대로를 적는다. 이 문서는 코드를 바꾸지 않는다.

| 항목 | 지금 동작 |
|---|---|
| 파일 | `garment_mask.png`(어댑터 산출물 `{job_id}_render_mask.png`), 8비트 흑백 PNG, 무손실 |
| 크기 | 768 × 1024(가로 × 세로), 렌더 정지 프레임·클립과 같은 카메라·같은 크기 |
| 값 | 옷 255, 나머지 0. 중간값 없음 |
| 방향 | 파일의 첫 행이 화면 맨 위(cv2·PIL로 읽은 그대로). Blender 안의 픽셀 배열은 아래 행부터지만 저장한 PNG는 바로 서 있다 |
| 옷 픽셀 | 픽셀 **가운데 한 점**에서 카메라 광선이 처음 닿는 면이 옷이면 255. Cycles CPU, 1샘플, 픽셀 필터 0.01 px, 옷은 흰색 발광(1.0), 몸은 검정 발광(0.0), 배경 검정, 임계값 0.5 |
| 팔·몸에 가려진 옷 | **빠진다.** 몸은 불투명한 검정 물체라 몸(팔 포함) 뒤의 옷은 0이다. "옷 전체 모양"이 아니라 "정면에서 **보이는** 옷"이다 |
| 옷 안쪽 | **들어간다.** 옷 메시는 두께 없는 천이고 Cycles 렌더는 뒷면을 빼지 않는다. 목둘레 안으로 보이는 뒤판 안쪽, 소매 안쪽이 보이면 255다. 시연 티셔츠 2벌은 목·몸이 목둘레 안을 거의 가려 뒤쪽 깃 위 끝 몇 픽셀만 보인다 |
| 경계 안티에일리어싱 | **없다.** 1샘플·필터 0.01 px라 경계 픽셀도 0 또는 255다. 경계 위치는 픽셀 가운데 점 기준이다(정지 프레임의 경계와 최대 약 1 px 차이) |
| 화면 밖 | 뒤쪽 깃 위 끝이 화면 맨 위에 닿아 잘린다(`docs/render.md` 5절, 머리를 화면 밖에 두는 프레이밍). 시연 티셔츠 2벌 모두 마스크 0행에 옷 픽셀이 있다 |
| 재현성 | 같은 `.blend`를 두 번 렌더하면 마스크가 픽셀까지 같다(4절 표, IoU 1) |
| 프레임 | **정지 클립**이라 마스크 1장이 121프레임 모두에 해당한다. 프레임별 마스크를 따로 만들지 않는다 |

- 렌더 어댑터는 마스크를 계약 출력(`RENDER_OUTPUTS`)에 넣지 않고 지표 `render_mask_artifact_id`로 알린다. 계약 출력에 넣을지는 B·D 결정으로 남긴다(`docs/render.md` 8절).

## 2. 실사 영상 프레임과 비교할 때 맞출 것

1. **크기·종횡비**
   - 렌더는 768 × 1024(3 : 4)다.
   - fal/LTX `720p`는 짧은 변 720 기준으로 비율을 유지한다(`docs/spikes/fal-ltx-render-to-real.md`). 768 × 1024 입력이면 720 × 960(같은 3 : 4)으로 예상한다.
     - 아직 C5 클립으로 실사화한 결과는 없다. D 실행에서 실제 크기를 확인해야 한다.
   - **종횡비가 다르면 비교하지 않는다(측정 불가로 본다).** 늘이거나 잘라 맞추지 않는다(명세서 7장 "억지로 늘리거나 회전시켜 통과시키지 않는다").
2. **크기가 다를 때 줄이는 방법 [제안]**
   - 렌더 마스크를 실사 프레임 크기로 **최근접 보간**(`cv2.INTER_NEAREST`)으로 줄여 그 크기에서 비교한다.
   - 쌍선형 등으로 줄이면 경계에 중간값이 생긴다. `fitting.verify.silhouette`는 0/255 외의 값을 오류로 본다.
   - 768 × 1024 → 720 × 960 → 768 × 1024 최근접 왕복만으로 IoU 0.990~0.992, 경계 HD95 1.4 px가 바뀐다(4절). 크기 변환 자체가 이 정도의 차이를 만든다.
3. **시간**
   - 렌더는 정지 클립이라 어느 실사 프레임이든 같은 렌더 마스크와 비교한다.
   - 실사 쪽 대표 프레임·11프레임 선택과 길이·fps 보정은 D5·D6 몫이다.
4. **좌표**
   - 카메라·프레이밍은 의류마다 다르다(옷 경계 상자에 맞춘다, `docs/render.md` 5절). 그래서 서로 다른 옷의 마스크는 다른 카메라에서 찍은 것이다.
   - 실사 프레임은 같은 렌더에서 나오므로 같은 좌표다.

## 3. 형태 값 (`fitting/verify/silhouette.py`)

numpy만 쓴다. 입력은 2차원 bool 또는 0/255·0/1 정수 마스크다. 빈 마스크는 `EmptyMaskError`(0으로 숨기지 않는다), 크기가 다르면 `ValueError`다.

### `mask_shape(mask)` — 마스크 하나

| 키 | 뜻 |
|---|---|
| `area_px`, `area_ratio` | 옷 픽셀 수, 이미지 대비 비율 |
| `bbox_px`, `bbox_norm`, `bbox_size_px` | 바운딩 박스 [x0, y0, x1, y1](px 끝 포함 / 이미지 크기로 나눈 값, 끝은 x1+1), 박스 가로·세로 |
| `centroid_px`, `centroid_norm` | 무게중심(px / 픽셀 가운데 기준 정규화) |
| `hem_row_px`, `hem_norm` | 밑단 높이 = 가장 아래 옷 행 |
| `widths[]` | 박스 맨 위에서 박스 높이의 `level` 비율인 행을 가운데로 둔 5행에서 행마다 "가장 왼쪽 ~ 가장 오른쪽 옷 픽셀" 폭을 재고 그 중앙값(`width_px`). `width_rel` = 폭 / 박스 높이 |
| `symmetry_iou`, `symmetry_diff` | 박스 가운데 세로선으로 좌우 반전한 마스크와의 IoU, 1 − 그 값(0이면 대칭) |

- 기본 높이는 0.15 · 0.45 · 0.90이다.
  - 0.45(가슴)·0.90(밑단)과 "주변 5행 중앙값"은 명세서 7장 정의 그대로다.
  - 0.15는 어깨·소매 쪽 폭을 보려고 더했다.
- 폭은 픽셀 개수가 아니라 끝에서 끝까지 거리다. 팔에 가려 가운데가 비어도 폭은 바뀌지 않는다.

### `compare_masks(ref, other)` — 두 마스크(같은 크기)

ref는 렌더, other는 실사 프레임 마스크로 쓴다.

| 키 | 뜻 |
|---|---|
| `iou` | 교집합 / 합집합 |
| `area_ratio`, `area_ratio_diff` | other 넓이 / ref 넓이(명세서 7장 "0.5배 미만·1.5배 초과면 측정 불가"에 쓰는 값), 이미지 대비 비율의 차 |
| `centroid_shift_px`, `centroid_shift_dist_px` | 무게중심 이동 [dx, dy](other − ref, 아래·오른쪽 +)와 거리 |
| `hem_shift_px` | 밑단 이동(+면 other 밑단이 아래) |
| `widths[]` | **ref 박스로 정한 같은 행**에서 잰 ref·other 폭, 차(px), 변화율(other / ref − 1). 명세서 7장 "원본 바운딩 박스 기준 위치" |
| `boundary_hd95_px` | 경계 95 % Hausdorff 거리 |
| `symmetry_diff_change` | 좌우 대칭 차이의 변화 |

**경계 거리는 HD95를 골랐다.**
- 정의
  - 경계 픽셀은 4-이웃 중 옷이 아닌 픽셀(이미지 밖 포함)이 있는 옷 픽셀이다.
  - 각 경계 픽셀에서 다른 쪽 경계까지 최소 거리를 잰다.
  - 두 방향 각각의 95 백분위 중 큰 값이다(MedPy `hd95`와 같은 방식).
- 근거
  - 대칭 평균 경계 거리는 경계 대부분이 맞으면 소매 하나가 사라지는 것 같은 국소 변형을 희석한다. 시연 티셔츠 경계는 약 2,350 px이고 소매 끝은 그 몇 %다.
  - 최대 Hausdorff는 분할 잡음 1픽셀에 끌려간다.
  - HD95는 5 % 넘는 경계가 어긋나야 커지므로 그 사이다. 테스트에서 멀리 떨어진 1픽셀 잡음에는 0, 아래로 30행 늘어난 마스크에는 20 px 이상이었다.
- 계산은 경계 점끼리 거리를 나눠서 구한다(numpy). 768 × 1024 시연 마스크 한 쌍 비교(`compare_masks`)에 약 0.16초였다.

관찰
- 같은 렌더 두 번은 모든 값이 0이다. 렌더 쪽 잡음은 없다.
- 경계 3 px 침식·팽창, 크기 ±2 %, 4 px 이동은 모두 IoU 0.95 이상, HD95 7.1 px 이하, 밑단 이동 6 px 이하, 폭 변화(0.45·0.90) 2.6 % 이하였다.
  - 0.15(소매 끝 쪽)는 크기 변화에 더 민감해 4.5 %까지 갔다. 박스 위쪽 15 %는 소매 끝이 폭을 정한다.

  - 대신 밑단 이동(47 px)과 HD95(41 px)는 교란 범위(≤ 6 px, ≤ 7.1 px)와 크게 떨어진다.
- 가슴(0.45) 폭은 다른 옷에서 5.7~10.4 % 바뀌었다. 명세서 7장의 "5 % 이내"는 두 옷을 겨우 가른다.

## 5. "같은 옷으로 볼 수 있는 범위" [제안]

D6가 판정 기준을 정할 때 출발점으로 쓰는 값이다. 근거는 4절 표다. 판정 코드에는 넣지 않았다.

| 값 | [제안] | 근거 |
|---|---|---|
| IoU 하한 | **0.90** | 교란 최저 0.950과 다른 옷 0.858의 거의 가운데. 명세서 초기값 0.85는 다른 옷(0.858)을 통과시킨다 |
| 밑단 이동 상한 | **±12 px**(시연 티셔츠 옷 높이 585~632 px의 약 2 %) | 교란 최대 6 px의 두 배, 다른 옷 47 px의 약 1/4 |
| 경계 HD95 상한 | **15 px** | 교란 최대 7.1 px의 약 두 배, 다른 옷 41 px의 약 1/3 |
| 가슴(0.45)·밑단(0.90) 폭 변화 | **±5 %**(명세서 7장 그대로) | 교란 최대 2.6 %, 다른 옷 5.2~10.4 % |
| 넓이 비 | **0.5~1.5배 밖이면 측정 불가**(명세서 7장 그대로) | 교란은 0.96~1.04 |
| 0.15 폭, 무게중심 이동, 좌우 대칭 | 기록만 [제안] | 소매 끝이 정해 크기 변화에 민감(4.5 %). 중심 이동은 다른 옷도 19.5 px로 작다 |

한계
- **근거가 시연 티셔츠 2벌뿐이다.** 다른 옷 비교도 한 쌍이고, 두 옷의 카메라가 다르다(2절 4).
- 교란은 경계 전체에 고르게 준 것이다. 실제 실사화는 주름·박음질을 더하거나 소매 끝을 국소로 바꾼다. 실사 영상 3개 이상을 본 뒤 다시 정해야 한다(3주 계획 "실사화 검증 기준" 항목).
- 실사 프레임 마스크(SAM 2 등 분할)의 잡음은 포함하지 않았다. 분할 잡음이 2~3 px이면 IoU 0.96~0.97 정도가 바닥이 된다(침식·팽창 행).
- 픽셀 값은 768 × 1024 기준이다. 720 × 960에서 비교하면 px 기준(밑단 12 px, HD95 15 px)에 720/768 = 0.9375를 곱한다 [제안].

## 6. 착장 설정 차이 (C6 일괄 착장, 같은 의류 drape_v1 · drape_v2_candidate)

일괄 착장(`tools/drape_batch.py --render`, 원단 매핑 켬, 몸 mean_all)에서 같은 의류를 두 설정으로 입히고 렌더해 마스크를 비교했다. 두 설정에서 모두 통과한 5벌(시연 티셔츠 2, AI Hub 4벌)만 렌더가 있다. ref는 drape_v1이다. AI Hub는 범위만 적는다.

| 경우 | IoU | 넓이 비 | 중심 이동 px | 밑단 이동 px | 폭 변화 0.15 / 0.45 / 0.90 | HD95 px |
|---|---|---|---|---|---|---|
| 티셔츠 2, v1 → v2c | 0.8965 | 0.952 | 16.3 | −38 | +7.0 % / −1.6 % / −6.0 % | 32.6 |
| AI Hub 4벌, v1 → v2c (범위) | 0.820~0.920 | 0.94~1.08 | 3.3~32.6 | −26~+46 | 0.45에서 −20.7 %~+35.9 % | 20.9~49.0 |
| 티셔츠 1, C5 마스크 → C6 v1 다시 착장 | 0.9849 | 1.001 | 1.9 | −1 | +1.1 % / 0 / +0.6 % | 3.0 |
| 티셔츠 2, C5 마스크 → C6 v1 다시 착장 | 1.0000 | 1.000 | 0 | 0 | 0 / 0 / 0 | 0 |

관찰
- **착장 설정만 바꿔도 5벌 모두 5절의 [제안] "같은 옷" 범위(IoU 0.90, HD95 15 px)를 벗어났다.** 다른 두 티셔츠의 차이(IoU 0.858, HD95 41 px)와 비슷한 크기다. 실사 영상과 비교할 렌더는 착장 설정을 고정하고 그 설정을 기록해야 한다.
  - 이 차이에는 프레이밍이 의류의 착장 결과마다 다시 정해지는 몫(카메라 위쪽 = 깃 + 3 cm)도 들어 있다. 착장 결과의 차이와 카메라의 차이를 나누지는 않았다.
- 티셔츠 1은 C5와 같은 입력(drape_v1, 원단 매핑 켬)으로 다시 입혔는데 최대 신장이 1.445 → 1.448로 바뀌고 마스크도 조금 달랐다(IoU 0.985, HD95 3 px). 교란 범위 안이지만 같은 입력에서 착장이 완전히 같게 나온다고 볼 수는 없다. 티셔츠 2는 같았다. 원인은 확인하지 않았다.
